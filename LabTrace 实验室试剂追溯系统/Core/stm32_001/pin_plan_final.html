协议和接线规则

  1. ESP8266：PA2 = USART2_TX 接模块 RXD；PA3 = USART2_RX 接模块 TXD。ESP 负责 MQTT，STM32 只发 AT 指令。PB5 控制 RST；IO_0 通过 10k 上拉到 3.3V，烧录时才拉低。
  2. DHT11：PA1 为单总线 DATA，数据线加 4.7k~10k 上拉到 3.3V；读取间隔至少 1 秒。
  3. RC522：PA5/PA6/PA7 使用 SPI1；模块的 SDA 在 SPI 接法里是 CS/NSS，不是 I2C SDA；RQ/IRQ 不接，先轮询。
  4. W25QXX：PB13/PB14/PB15 使用 SPI2；D0/DO = MISO，D1/DI = MOSI，PB12 为 CS。标准电源脚通常是 VCC/VDD 和 GND/VSS，按实物丝印确认。
  5. DS3231：PB6/PB7 使用 I2C1；SCL/SDA 需要 3.3V 上拉，32K/SQW 暂不接。

CubeMX 参数

  1. SPI1：Full-Duplex Master，NSS=Software；PA4 GPIO_Output 作 RC522_CS，PA11 GPIO_Output 作 RC522_RST。
  2. SPI2：Full-Duplex Master，NSS=Software；PB12 GPIO_Output 作 W25Q_CS。
  3. TIM2：PA0 / TIM2_CH1 PWM。72 MHz 定时器时钟可设 Prescaler=71、Period=19999，得到 50 Hz；先用 0.5~2.5 ms 脉宽校准角度。
  4. I2C1：PB6=SCL、PB7=SDA，开漏复用，先用 100 kHz。
  5. 调试：SYS → Debug 选择 Serial Wire，保留 PA13/PA14；这样才可释放 PA15 给蜂鸣器。PB3/PB4 先保留。
  6. 定时器：当前 TIM3 是 HAL 时间基准，不要拿 TIM3 做舵机 PWM。

供电和实现顺序

龙邱电源的 3.3V 给 ESP8266、RC522、W25QXX、DHT11、DS3231；5V 给 SG90、HC-SR04、蜂鸣器。SG90 电源不要接 STM32 3.3V。HC-SR04 的 Echo 使用 1kΩ 串联、2kΩ 下拉分压后接 PB8，Trig 接 PB9。蜂鸣器 I/O 接 PA15，LED 串联 220~1kΩ 电阻后接 PA8。HX711 的 DT/SCK 接 PB0/PB1，建议先用 3.3V 供电。

实现顺序：保持 USART1/USART2 通信不变，依次单独验证 SG90、DHT11、HX711、W25QXX、RC522、DS3231，再接入 FreeRTOS 队列、W25QXX 离线缓存、故障日志和 IWDG。IWDG 是片内外设，不占 GPIO，最后由 HealthTask 统一喂狗。

引脚名称和 LQFP48 脚号按 STM32F103C8T6 引脚定义参考资料整理。模块协议按常见数据手册：ESP8266=UART/AT+MQTT，DHT11=单总线，RC522/W25QXX=SPI，DS3231=I2C，SG90=50 Hz PWM，HX711=两线串行。

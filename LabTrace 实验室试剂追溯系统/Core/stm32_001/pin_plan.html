CubeMX 建议

  1. USART1：PA9 TX、PA10 RX，115200，连接 USB-TTL。
  2. USART2：PA2 TX、PA3 RX，115200，连接 ESP8266。
  3. SPI1：PA5 SCK、PA6 MISO、PA7 MOSI，PA4 作为 RC522 CS，PA11 作为 RC522 RST。
  4. SPI2：PB13 SCK、PB14 MISO、PB15 MOSI，PB12 作为 W25QXX CS。
  5. TIM2 PWM：PA0 / TIM2_CH1，SG90 使用 50 Hz，占空比按 0.5~2.5 ms 校准。
  6. I2C1：PB6 SCL、PB7 SDA，给 DS3231；总线需要上拉电阻。
  7. 调试：SYS → Debug 选 Serial Wire，保留 PA13/PA14；这样 PA15 可作为蜂鸣器 GPIO。
  8. TIM3：当前是 HAL 时间基准，不要拿 TIM3 给 SG90。

必须注意

  1. ESP8266、RC522、W25QXX 优先使用稳定的 3.3V 供电，ESP8266 峰值电流较大。
  2. USB-TTL 只接 3.3V 信号并共地；USB-TTL 的 RX 接 PA9，TX 接 PA10。
  3. HC-SR04 若使用 5V 供电，Echo 可能输出 5V，进入 PB8 前需要分压或电平转换。
  4. W25QXX 标准命名通常是 VCC、CS、DO、GND、CLK、DI；你写的 VSS 请先核对实际丝印，不能把电源脚误接地。
  5. RC522 的 RQ/IRQ 可以暂时不接，先轮询；RC522 两个 GND 都接公共地。
  6. SG90 的电源不要从 STM32 3.3V 供电，舵机动作会产生电流冲击。
  7. IWDG 不占用 GPIO，后续由 HealthTask 在确认关键任务正常后统一喂狗。

建议实现顺序

先保持 PA2/PA3 的 ESP8266 通信和 PA9/PA10 的调试通信不变。之后依次验证 SG90、DHT11、HX711、W25QXX、RC522、DS3231，最后再加 HC-SR04、蜂鸣器、LED、离线缓存和 IWDG。每新增一个模块，都先在独立 BSP 驱动中完成“初始化 + 单独测试”，再接入 FreeRTOS 队列。
